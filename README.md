# Social Monitor Bot (Instagram & TikTok)

Автономный Telegram-бот для мониторинга изменений в профилях **Instagram** (`@nasyy.k`) и **TikTok** (`@naasyyk`).

## Возможности
- ⏱ **Автоматическая проверка раз в 30 минут** в фоновом режиме.
- 📈 **Динамика подписчиков**: мгновенные уведомления о росте или оттоке (`+1`, `-2` и т.д.).
- 👥 **Динамика подписок**: отслеживание изменений списка `Following`.
- 🎥 **Новые видео TikTok**: определение публикации нового видео со ссылкой и названием.
- 📸 **Новые посты Instagram**: определение новых публикаций/Reels с прямой ссылкой.
- ✨ **Истории Instagram** (при указании `INSTAGRAM_SESSION_ID`).
- 📊 Команды бота:
  - `/start` — активация и регистрация вашего Telegram в списке получателей.
  - `/status` — моментальный отчет с текущими цифрами по обоим аккаунтам.
  - `/check` — запуск внеплановой проверки прямо сейчас.
  - `/help` — помощь по командам.

## Структура проекта
```text
social_monitor/
├── .venv/            # Виртуальное окружение Python
├── config.py         # Настройки: токен бота, цели, интервал проверки
├── database.py       # SQLite хранилище (подписчики бота и снимки профилей)
├── scrapers.py       # Модули сбора данных (curl_cffi + yt-dlp)
├── bot.py            # Основной скрипт бота с фоновым планировщиком
├── requirements.txt  # Список зависимостей
├── run.bat           # Файл для быстрого запуска в Windows
└── monitor.db        # База данных (создается автоматически)
```
